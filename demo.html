Markdown 渲染对比 Reins 改后 vs grok-build pretty

同一段 Markdown、同一宽度，左右各按一套规则渲染。左边是 Reins 按本轮要求改后的效果（六级标题、text (url)、蓝色加粗行内代码、盒线表格……）； 右边按 grok-build 的 xai-grok-markdown pretty 模式复刻。改上面的 Markdown 或拖动宽度，两边会实时重排。

两侧共用同一内容宽度（列）
Markdown 源 marked 解析 · 改动实时生效
Reins 改后2 空格缩进 · 单词换行

		

		

			
grok-build pretty源文本保真 · 单词换行

			

		

	


	

		
当前的主要差异

		
grok 侧按 xai-grok-markdown 的 pretty 规则复刻，颜色取自 groknight 主题，用于对比观感，不是 Rust 渲染器的逐像素输出。

		

			
01
代码块
Reins 保留上下留白和正文缩进，底色用更弱的一档 #111418；grok 顶格、无留白、每行 #1c1c1c。

			
02
任务列表
Reins 用 [x] 已完成 代替圆点；grok 保留圆点：• [x] 已完成，勾选框单独染色。

			
03
引用软换行
Reins 把引用里的软换行折叠成一行；grok 保留为多行，每行都带 │。

			
04
分割线
Reins 铺满整行；grok 只画 ─── 三个字符。

			
05
空行
Reins 块之间统一补一行；grok 尽量保留源文本里的空行数量。

			
06
表格表头
两边都是盒线表格、单元格左右留白并支持折行；Reins 表头加粗，grok 表头保持源文本样式（默认不加粗）。

			
07
图片
Reins 显示 [image: alt](url)；grok 显示 !alt (url)。地址都用弱化色。

			
08
配色
Reins 主文字 #e6e9ed、链接/行内代码 #61afef；grok 主文字 #c8c8c8、链接 #7aa6da、行内代码 #3A95AB。

			
09
标题调色板
两边都是六档；Reins 用主题里的青/蓝/紫/次灰/弱灰/暗灰，grok 用 groknight 的青/蓝/紫/亮灰/中灰/暗灰。
