# Reins 桌面端界面重设计方案

> 状态：评审稿。配套演示 `docs/design/demo.html`（单文件，可直接在浏览器打开）。
> 本文只描述视觉与交互，不含实现细节；落地时按现有模块边界逐项对应。

## 一、设计定位

Reins 是一个在终端里替人干活的编码智能体。用户 90% 的时间在做两件事：**看 agent 在做什么**，以及**决定要不要让它继续**。界面不该是聊天窗，而应该是一份**排版精确的工作记录 + 一个克制但明确的控制台**。

由此得出四条判断，它们决定了后面所有取舍：

| 判断 | 含义 | 反面（现状的问题） |
| --- | --- | --- |
| 会话是文档，不是聊天 | 提问、回答、工具调用按文档层级排布，去掉气泡与居中大钮 | 气泡让长会话变成一条条碎片，难以回顾 |
| 状态必须有形状 | 状态不能只靠颜色，必须同时有形状、纹理、文案 | 彩色语义点在灰度屏/色弱下失效 |
| 危险操作整块反白 | 黑白系统里最响的信号是"整块倒过来" | 红色被泛用，语义被稀释 |
| 线宽即层级 | 0.5px 分隔 / 1px 结构 / 2px 强调 / 整块填充 | 卡片 + 投影层层浮起，层级靠阴影堆 |

## 二、配色

### 2.1 原则

**界面零彩色，例外：diff、危险动作、滑杆渐变、图表分类色。** 不设品牌色、不用 success / warning / destructive 三色，强调色就是墨本身。每处例外都有数据或动作语义：diff 红绿 = 增删（主流 agent 一致）；拒绝按钮红 = 止损；思考强度滑杆渐变 = 档位能量；上下文构成的分类色 = 区分数据大类。它们都不承担界面状态语义，不会稀释危险闸门的反白。

这不是审美偏好，是三条实际理由：

1. **危险信号不被稀释** —— 彩色方案里红色同时表示"错误""删除""超时""失败"，用户会逐渐钝化。黑白方案里**整卡反白**只用于不可逆确认这一处；实心填充仍用于按钮与控件，但只出现在控件尺度，深浅主题皆然。卡片级的整块倒转是唯一的，语义不会磨损。
2. **色觉障碍零影响** —— 红绿色弱约占男性 8%，黑白系统对他们完全等价。
3. **两套主题共用一套规则** —— 彩色需要在明暗两套下各自调校对比度；明度阶梯天然可反转。

### 2.2 令牌

| 令牌 | 浅色 | 深色 | 用途 |
| --- | --- | --- | --- |
| `--paper` | `#f6f6f5` | `#090909` | 窗口底、侧栏 |
| `--sheet` | `#fdfdfc` | `#111111` | 主内容面、右面板 |
| `--raise` | `#ffffff` | `#191919` | 输入卡、浮层、按钮 |
| `--sunken` | `#f0f0ee` | `#0d0d0d` | 代码块、只读区、底栏 |
| `--wash` | `rgba(0,0,0,.034)` | `rgba(255,255,255,.045)` | 悬停、弱填充 |
| `--wash-2` | `rgba(0,0,0,.066)` | `rgba(255,255,255,.082)` | 选中、次级填充 |
| `--ink` | `#0b0b0b` | `#f2f2f0` | 正文、强调、实心填充 |
| `--ink-2` | `#545454` | `#a5a5a1` | 次文本、标签 |
| `--ink-3` | `#8a8a8a` | `#717170` | 辅助信息、图标 |
| `--ink-4` | `#b6b6b4` | `#494948` | 占位、最弱层级 |
| `--rule` | `rgba(0,0,0,.085)` | `rgba(255,255,255,.09)` | 分隔线、行边框 |
| `--rule-2` | `rgba(0,0,0,.16)` | `rgba(255,255,255,.18)` | 结构线、控件描边 |
| `--rule-3` | `rgba(0,0,0,.30)` | `rgba(255,255,255,.32)` | 聚焦、强调描边 |
| `--fill` / `--fill-ink` | `#0b0b0b` / `#fdfdfc` | `#f2f2f0` / `#090909` | 实心块与其反白文字 |
| `--diff-add-bg` / `--diff-del-bg` | `#e9f6ec` / `#fdeded` | `rgba(63,185,80,.14)` / `rgba(248,81,73,.16)` | diff 增 / 删行底色（彩色例外） |
| `--danger` / `--danger-soft` | `#cf222e` / `#fdeded` | `#f85149` / `rgba(248,81,73,.16)` | 危险动作（拒绝按钮）描边与悬停底（彩色例外） |

### 2.3 对比度

| 组合 | 比值 | 结论 |
| --- | --- | --- |
| `ink` on `sheet` | 18.9:1 | AAA |
| `ink-2` on `sheet` | 7.6:1 | AAA |
| `ink-3` on `sheet` | 3.2:1 | 仅限 12px 以上辅助文本、≥10px 等宽大写刻字与非文本标识（满足 AA 对图形 3:1 的要求） |
| `fill-ink` on `fill` | 18.9:1 | AAA，反白卡正文 |

`ink-3` 不允许承载正文或需要精确阅读的信息。允许的用途：12px 以上的辅助文本；≥10px 的等宽大写刻字（信息在别处冗余或纯装饰）；图标与计量单位。

`ink-4` 只用于占位符、时间戳、悬停瞬态信息与纯装饰，不允许承载唯一的操作信息——快捷键、错误说明这类"不看就做不了"的内容必须用 `--ink-2` 及以上。审批卡等安全表面的文字提示，一律比常规辅助文本再高一级。

### 2.4 终端与代码的灰度映射

零彩色必须覆盖真实终端输出与语法高亮，否则第一次运行测试就会被 ANSI 颜色打破。规则：颜色信息降级为「明度 + 字重」二元组，不引入新令牌；终端**不透传** ANSI 颜色。

| 来源 | 映射 |
| --- | --- |
| ANSI 强调色（红 / 黄 / 品红及亮色变体） | `--ink` + 字重 500 |
| ANSI 常规色（绿 / 青 / 蓝） | `--ink-2` |
| ANSI 暗色变体 / 灰 | `--ink-3` |
| ANSI 加粗 | 字重 600 |
| ANSI 下划线 / 反色 | 下划线保留；反色转 `--fill` / `--fill-ink` |
| 语法关键字 | `--ink` + 字重 600 |
| 语法字符串 / 数字 | `--ink` |
| 语法其余 / 标点 | `--ink-2` |
| 语法注释 | `--ink-3` |

映射不承担唯一语义：失败行仍有斜纹底、图标与文案，颜色映射只负责让输出保持层级可读。

## 三、字体

离线工具不依赖网络字体，坚持系统栈。**个性放在处理上，不放在字体选择上**：

- 标题：收紧字距（`-0.028em`），字号大而字重不过重（600），形成"印上去"的实感。
- 小标签：等宽 + 大写 + `0.12em` 字距，形成仪表刻字感。
- 中文小标签：`0.17em` 字距，让 10px 的中文在小尺寸下仍有呼吸。

### 3.1 十级阶梯（只允许这十级）

| 字号 | 字重 | 字距 | 用途 |
| --- | --- | --- | --- |
| 36 | 600 | -0.032em | 空态主标题（每屏最多一处） |
| 27 | 600 | -0.024~0.028em | 文档/设置页标题 |
| 20 | 600 | -0.02em | 章节标题 |
| 16 | 600 | -0.012em | 卡片标题、小节 |
| 14 | 400 | -0.003em | 正文、提问 |
| 13 | 500 | -0.008em | 界面基准：会话标题、按钮 |
| 12 | 400 | 0 | 路径、代码、行内标记（等宽） |
| 11 | 500 | 0.12em | 仪表刻字、读数（等宽大写） |
| 10 | 500 | 0.17em | 中文小标签 |
| 9 | 500 | 0.12em | 等宽大写微刻字：徽标、快捷键提示（仅限短标签，不用中文） |

正文行高 1.72–1.78，界面元素 1.5，等宽读数 1.6。

### 3.2 字体栈

```
--sans: -apple-system, BlinkMacSystemFont, "Segoe UI", "PingFang SC",
        "Hiragino Sans GB", "Microsoft YaHei", "Helvetica Neue", Arial, sans-serif;
--mono: "SF Mono", "JetBrains Mono", "Fira Code", Consolas,
        "Liberation Mono", Menlo, Courier, "PingFang SC", "Microsoft YaHei", monospace;
```

### 3.3 文本符号与平台验收

- 图标统一 Lucide；`▶` `✓` 这类文本符号必须携带 `U+FE0E`（文本呈现变体选择符），避免被系统字体渲染成彩色表情。
- 中文展示级字号（27 / 36）在 Windows 上落到雅黑，观感比 PingFang 笨重。每次视觉验收必须包含 Windows 实机渲染截图，必要时对中文大标题降一档字重。

## 四、布局

### 4.1 三栏框架（保留现状结构）

```
┌──────────────────────────────────────────────────────────────┐
│ 标题栏 34px  [栏开关][搜索][←][→]      面包屑        [– □ ×]  │
├──────────┬────────────────────────────────────┬──────────────┤
│          │ 会话头 44px                         │ 页签条 36px  │
│ 侧栏     │  ┌──────────────────────────────┐  │              │
│ 244px    │  │ 内容列 max 820px，居中        │  │ 右面板       │
│ 可拖拽   │  │  └ 正文 780px                 │  │ 308–420px    │
│ 180–320  │  └──────────────────────────────┘  │ 可拖拽/全屏  │
│          │ 输入卡（同宽，贴底）                │              │
└──────────┴────────────────────────────────────┴──────────────┘
```

与现状一致的约束：侧栏可拖 180–320px，右面板可拖 360px 起，面板可全屏（主列折叠为 0），窗口变窄时自动收起右面板。**三栏齐平，不浮起**：去掉现状主列 16px 圆角上浮的做法，改用 1px `--rule-2` 竖线分区。

### 4.2 间距

只用 4 的倍数：`4 / 8 / 12 / 16 / 20 / 24 / 32 / 40 / 60`。组件内边距 8–14，区块间距 16–28，章节间距 40+。

### 4.3 圆角

`3px`（徽标、复选框）/ `5px`（按钮、输入框、菜单项）/ `7px`（卡片、浮层）/ `10px`（输入卡、模态）。现状的 28px 面板圆角在桌面工具上过于柔软，改为 7px。**不再出现全圆角胶囊**（除状态点与开关）。

### 4.4 投影

只有两个层级，且只用于**真正浮起的元素**：

- `shadow-1`：`0 1px 2px rgba(0,0,0,.04)` —— 输入卡静息
- `shadow-2`：`0 1px 2px rgba(0,0,0,.05), 0 10px 28px -10px rgba(0,0,0,.14)` —— 输入卡聚焦、菜单、浮层、模态

### 4.5 滚动条

**全应用只有一种滚动条**：10px 宽的透明轨道 + 内侧 4px 的 `--rule-2` 胶囊滑块，悬停转 `--rule-3`，两端不带按钮。会话流、浮层、侧栏、面板共用同一套规则，不允许某个容器单独写。

实现上只用 `::-webkit-scrollbar` 系列：**一旦同时声明标准的 `scrollbar-width` / `scrollbar-color`，Chromium 会退回原生滚动条**，`::-webkit-scrollbar` 全部失效，两端的系统箭头也会回来——这是这套样式最容易踩的坑。

### 4.6 侧栏

- **两大区，按归属分层**：「任务」区放未绑定项目的会话，按 进行中 / 今天 / 昨天 分组；「工作区」区放绑定了项目的会话，按所属项目分组（chevron + 文件夹图标 + 等宽字名称，可整组折叠）。一个会话要么在任务区，要么在某个工作区下，不会两处同时出现。侧栏不显示计数。
- **字体参与区分**：工作区名是目录标识，用等宽字；任务标题用正文字体。区名（任务 / 工作区）是小号宽字距标签，时间小节再弱一级。
- **侧栏只保留有信息量的状态**：会话行仅显示 运行（loader）/ 待确认（感叹圆）/ 已中断（禁止圆）；已完成与空闲不显示任何标识——一列灰对勾是噪音，留白即"无事"。图标槽位保留，各行标题对齐不变。
- **会话「更多」菜单**：重命名（`F2`）、移动到工作区 / 移出到任务区（随会话所在区互换方向）、归档、删除此任务。菜单打开期间，所在行呈选中态、操作钮保持可见。删除是唯一危险项，用字重 500 + 图标标注，不引入彩色。置顶保留为悬停快捷钮，不进菜单。
- **工作区组的操作菜单**（组头悬停浮现；菜单打开期间组头呈选中态、触发钮保持可见）：新建任务（在此工作区）、重命名、在资源管理器中显示、移除工作区。**移除工作区时，组内会话一律归档**——可在设置 · 已归档任务中找回；菜单底部一句话说明去向（「组内 2 个会话将归档，不删文件」）。若要连同会话删除整个工作区，属不可逆操作，走反白闸门，由内核处理，不在此菜单内。
- 顶部固定：品牌行、新建任务、搜索、定时任务 / 扩展管理入口；**底部为用户标识 + 设置齿轮图标**。侧栏不设「已归档」入口——归档任务由设置页「已归档任务」承载，会话右键菜单仍可归档。

## 五、定位与回溯：状态条读数 + 消息轨 +「回到最新」

长会话需要回答两个问题："我改到第几轮了？刚才那个决定在哪？"。调研主流 agent 界面（Codex、Claude Code 桌面端、dsh、workbuddy）后确认：**没有一家使用常驻导轨**——定位是低频需求，不值得常驻占宽。三者分工：

- **状态条读数**：`4 轮 · 19 步` 常驻于输入卡下方，直接回答"改到第几轮"。
- **右缘消息轨**（保留现状机制）：悬停展开，列出每轮提问锚点，点击跳转。负责"跳到某轮"。
- **「回到最新」胶囊**：滚离正在执行的回合时在会话底部浮现，点击回到执行位。运行中离开再回来，是最高频的定位场景。

初版方案的左缘常驻刻度轨**撤回**：它占 40px 通栏、使正文列无法居中，而提供的信息被上面三者覆盖；主流工具亦无先例，徒增陌生感。

## 六、组件库

### 6.1 按钮

| 变体 | 外观 | 用途 |
| --- | --- | --- |
| solid | `--fill` 底 + `--fill-ink` 字 | 每屏最多一个主动作 |
| line | 1px `--rule-2` 描边 + `--raise` 底 | 次动作 |
| ghost | 无底无框，悬停 `--wash` | 三级动作、图标按钮 |
| dashed | 1px 虚线描边 | "边界之外"的动作 |
| danger | 1px `--danger` 描边 + `--danger` 字 | 拒绝、删除等止损动作 |
| link | 下划线 | 内联跳转 |
| disabled | 38% 不透明度 | 不可用 |

尺寸：24 / 28 / 34px 高，对应 11 / 12 / 14px 字。图标按钮同高同宽。

### 6.2 表单控件（本次补齐的缺口）

现状没有通用 Input / Textarea / Checkbox / Radio / Segmented，全部就地写原生标签。补齐后统一：

- **Input**：30px 高，1px `--rule-2`，聚焦时边框转 `--ink` + 3px `--wash-2` 光环。
- **错误态**：边框转 `--ink`，下方提示前置图标 + 说明文字，**不用红色**。
- **Switch**：32×18px，关闭时描边空心 + `--ink-2` 圆点，开启时 `--fill` 底 + `--fill-ink` 圆点位移 14px。命中区向外扩到 44px。
- **Checkbox**：15×15px，勾选即 `--fill` 实心 + 反白对勾。
- **Radio**：同心圆，选中时外环 2px `--ink`。
- **Segmented**：`--sunken` 底槽 + 选中项 `--raise` 白片 + 1px 微影。

### 6.3 状态标识（纯黑白的核心）

图标与主流 agent 同一套语言（lucide），靠明度分级而非颜色区分轻重：

| 状态 | 图标（lucide） | 明度/纹理 | 文案 |
| --- | --- | --- | --- |
| 运行中 | `loader-circle`（旋转） | 实心墨 | 工具卡读数前旋转 loader；发送钮变实心方块 |
| 待确认 | `circle-alert`（感叹圆） | 实心墨 + 整卡 1px 描边 + 投影 | 标题「需要确认」 |
| 已完成 | `check`（对勾） | 最弱明度（ink-4） | 侧栏不显示标识，留白表示无事；悬停才出现操作 |
| 已中断 | `circle-slash`（禁止圆） | 次级明度（ink-2） | 工具卡标注「已中断」 |
| 空闲 | 弱化圆点 | 最低对比 | 侧栏不显示标识；不写文案 |
| 失败 | `circle-x`（叉圆） | 45° 斜纹底 | 「类型错误 1」等具体摘要 |

**四重编码**：图标 + 纹理 + 明度 + 文案。任一通道失效仍可辨识。

### 6.4 浮层

菜单 / 弹出层 / 提示 / 模态全部走 Portal。统一规格：1px `--rule-3` 边框、`--raise` 底、`shadow-2`、7px 圆角。菜单项 28px 高，右侧可挂快捷键（`--ink-4` 等宽 9px）。危险项不加红色，改用字重 500 + 图标。

### 6.5 加载与空态

- **加载**：4 个 4px 方点依次明暗（与产品既有像素动效语言一致），不用通用圆环。
- **进度条**：2px 高，`--rule-2` 槽 + `--ink` 填充；不确定进度用 32% 宽度滑块往复。
- **空态**：图标框 + 一句标题 + 一句说明 + 一个动作按钮。说明必须告诉用户"下一步做什么"，不写"暂无数据"。

## 七、核心页面

### 7.1 会话工作台

- **会话头 44px**：标题（13px/600）+ 右侧读数（等宽 10px：tok/s / 费用）+ 两个图标按钮。
- **提问**：右侧浅底气泡——`--wash` 底、10px 圆角、最大约 3/4 宽，正文 14px/1.72。**用户在右、模型在左**，与主流 agent 会话同构；不用等宽大写署名与通栏细线。文件路径用 `--wash` 底 + 等宽字内联标记。
- **回答**：正文直接开始，无导语行——"做了什么"由工具卡承载。正文按 14px 排版，列表用 5px 短横作项目符号。
- **思考块**：左侧 1px 细线，头部为大脑图标 + 一行摘要（「思考了 8 秒 · 3 个约束」），**默认折叠，点击整行展开/收起**，不设箭头。运行中图标脉动、文字渐变扫光。
- **待办槽位**：输入卡的位置就是「当前唯一需要你处理的事」。空闲时是输入卡；模型提问或等待审批时，整块输入卡让位给待办卡（同宽同位，状态条仍在下方），答完把结论落成流里的一条记录、槽位换回输入卡；**提问与审批共用一条队列**，先到先答，按 `1 / N` 顺序推进。两类卡的收尾不同：提问有 `×`（稍后：收成一行、点标题再展开，**不是取消**，取消要点「跳过」）；**裁决类不给 `×`**——越界请求只允许「拒绝 / 允许一次」，不许拖。卡片高度上限 48vh 内部滚动；出现时不抢焦点、不把会话流滚到底；答完自动滚到底，让人看见结论已经记账。**输入框上方三样东西的优先级**：待办卡占位（第一，此时输入框让位、补全不出现）＞ 补全浮层（第二，贴输入框上沿，可压过排队条）＞ 消息排队（第三，在卡内顶部）。
- **模型提问卡**：模型缺信息时停下并提问。与审批闸门同材质，但语义不同——闸门是**裁决**（允许 / 拒绝），这里是**补信息**（选一个），所以不反白、不用警示图标。头部 = 问号图标 + 问句 + 右侧 `1 / N` 计数 + `×`；选项为单选行（序号方块 + 标题 + 一行说明，选中后整行 `--wash-2` 底、序号反白、右侧勾）；末尾「其他补充…」自由输入与选项互斥但都能提交；底部左侧 `点选或按 1 / 2 · Enter 提交`，右侧「跳过」次操作 + 「提交」实体主操作（未选禁用，退回浅底浅字）。答完在流里留一条**只读记录**：`已选择 · <答案>` + 展开箭头，点开回看当时的选项（选中态保留、不可再点），展开后摘要退到底部变「收起」。**提交即送出，不设重选**——答案已成当轮输入，改口只能再发一条消息（服务端没有撤回已消费输入的通道，硬做还会与已执行的工具调用打架）。
- **选中引用**：会话流内划选文本，浮出「引用 / 复制」迷你工具条——引用以 `>` 块写入输入框并聚焦，复制写入剪贴板；滚动或点击别处即收。工具条跟随选区，选区贴顶时改弹下方。
- **轮末操作条**：每轮回答下方悬停显现——复制 / 重新生成 / 赞 / 踩四个图标，不占静态视觉重量；复制真实写入剪贴板。朗读、分享、每轮模型元数据不做（桌面编码工具场景弱，会话头已有），运行中的回合不显示。
- **工具卡**：单行，高 30px，网格 `16px 图标 | 1fr 摘要 | auto 读数`，**不显示折叠箭头**，整行可点。**按动作分流**：读取 / 搜索 / 列目录 / 运行折叠为一行摘要，点击展开参数与输出；新建 / 编辑**内联展示 diff**，点击行可收起/展开其 diff。连续同类调用折叠成组（"读取 2 个文件 · 搜索 1 处"），点开展开逐行明细。摘要用正常语气的动词开头（读取 / 搜索 / 编辑 / 运行），路径保持等宽。图标按动作语义映射，与主流 agent 一致：读取 = 文档、搜索 = 放大镜、列目录 = 文件夹组、新建/编辑 = 铅笔、运行 = 终端、技能 = 拼图、MCP 工具 = 连接器、审阅改动 = git-compare。技能与 MCP 调用也走同一张工具卡——摘要点名技能名 / 服务名（「执行 技能 frontend-design」「调用 连接器 web-reader」），不设特殊卡片。完成 = 右端留白，运行 = 读数前旋转 loader，失败 = 45° 斜纹底 + 行尾图标与摘要。
- **Diff**：对齐主流 agent 工具（ZCode / dsh / workbuddy）——**单列行号（显示序号，连续不跳号）+ 代码列**，无加减号列、无 `@@` hunk 头；增删行直接用红绿底色区分（`--diff-add-bg` / `--diff-del-bg`）。缩进一律空格呈现，不透传制表符。红绿只出现在 diff 内容里，不进入任何界面控件。
- **输入卡**：整屏唯一带投影的实体面。`--raise` 底、10px 圆角、12–14px 内边距。工具栏：`+` 圆钮（浮层**根级四项,每项带二级子菜单**,结构对齐主流:添加文件 / 引用工作区文件 / 技能 / 连接器（即 MCP）;「专家」「模式」不设——模式由模式选择器承担。子菜单:添加文件 = 上传文件(任意类型,不单列图片)/ 添加文件夹;引用 = 文件搜索 + 工作区文件;技能 = 搜索 + 技能列表(彩色字母标 + 名称 + 一句说明) + 从本地添加 / 管理技能;连接器 = MCP 服务列表 + 管理连接器;返回箭头回根级,动作项点即关)/ **模式选择器**（芯片 = **图标 + 当前档名**：常规态随审批方式显示 盾/眼/电 图标 + 档名，计划开启显示 地图图标 + 「计划模式」；浮层内**「计划模式」滑块开关置顶**——开启后只读调研、审批方式段禁用置灰；其下「审批方式」单选——逐次询问 / 自动审查 / 直接放行，选中即关）… **模型·思考合并选择器**（芯片「模型 · 思考 档位」，无图标；浮层两级——**第一级提供商列表**：logo + 名称 + 类型徽标（个人 / 免费 / API）+ 选中勾，底部「管理模型」入口；点提供商进入**第二级**：头部（返回 + 提供商名 + 徽标）→「模型」列表（选中勾在右）→「思考强度」行 + **绿→蓝渐变滑杆**、白色圆钮、`Ctrl 1` 循环提示——切档不关；进入提供商时若当前模型不在其下，自动落到该提供商的第一个模型）│ 发送钮（30px 方形；待命时静默灰钮——wash-2 底 + ink-3 图标，可用或停止时才转实体墨色，不用透明度硬降）。
- **输入补全**：词首的 `@`（引用文件）、`$`（调用技能）、`/`（命令 + 技能）触发浮层，**与输入卡同宽、贴着输入框上沿浮起**——它的位置跟输入框走，不跟整张卡走；有排队条时直接压过它（见下方优先级）。`/` 触发时**分组列出**：`命令` 在上、`技能` 在下，两组都带 9px 等宽组标题；**组内 token 列按最长一条定宽**，所以同组的说明起在同一条竖线上（命令与技能各排各的列）。每行 = 等宽 `token` + 同一行的一句说明（说明截断不换行），选中整行 `--wash-2`。底部常驻提示行：左侧「输入内容以搜索命令、技能或文件」，右侧键盘路径 `↑↓ 选择 · Enter 采纳`；列表超高时内部滚动。`↑ ↓` 移动、`Enter` / `Tab` 采纳、`Esc` 关闭；采纳后替换触发词并补一个空格。**只在词首触发**（`(^|\s)([@$/])([^\s@$/]*)$`），否则路径里的 `/` 会被当成指令；浮层打开时回车归浮层，不会把消息发出去。
- **状态条**：输入卡下方一行等宽 10px 读数，**整体居中**——dsh 式上下文圆环打头，点击弹出「上下文用量」面板：大百分比 + 已用/总量、分类分段条与明细（系统提示词 / 工具及子智能体 / 对话消息 / 连接及 MCP / 技能，分类色）、底部一行窗口档位说明；其后竖线分隔：`4 轮 · 19 步 | 62k · 命中 71%`。不放「已恢复会话」这类瞬态文案——状态条只承载数值读数，会话恢复信息由会话头或通知条承担。
- **消息排队**：回合进行中按 Enter 不丢消息也不打断，进「排队」条——挂在输入卡内顶部（不入卡帽、不浮在会话流上），标题 `排队 N 条 · 拖动排序 · 回合结束后依次发出`，每行 `把手 | 序号 | 正文 | 编辑 / 立即发送 / 撤回`。序号前的六点把手常驻（默认 45% 不透明度，悬停才清楚），拖动越过相邻行中线即换位；编辑为就地输入框（Enter 存、Esc 弃）；**立即发送 = 打断当前回合并发出**（服务端一次只跑一个回合、运行中提交返 409，没有中途注入通道，所以只有这一种语义），图标用实心闪电与撤回区分。**工具栏只保留一枚按钮**：回合进行中它就是停止（方形、实体墨色），不另设「排队」钮——多一枚箭头按钮会和停止抢主次，也让“发还是停”变成要读图标才能分清的事；排队一律走 Enter，输入框 placeholder 明写「Enter 加入队列」。队列按会话归属，清空后整条自动收起。
- **「回到最新」**：滚离正在执行的回合时，会话底部浮现胶囊按钮，点击回到执行位。

### 7.2 新建任务

三层信息，自上而下：

1. **这是什么** —— 36px 标题（收紧字距）+ 一行 13px 说明。整屏唯一展示级排版。
2. **在哪干活** —— 卡帽与输入卡是**两个兄弟组件，像一顶帽子轻轻扣在卡片上**：卡帽是一块 sunken 下沉底托板，可见高 34px，上两角 10px 圆角、只留上/左/右三边描边，左右内边距 5px（芯片的图标左缘与输入框文字左缘同列）；输入卡上移 8px 压住托板下缘，四角全圆、四周描边，帽檐留下 4px。顶部两角的缺口里露出底下的灰，形状上读成两层，而不是一条轮廓换色。卡帽上两枚芯片：**工作区**（等宽字目录名，点开是「搜索 + 最近工作空间 + 新建工作空间 / 打开本地文件夹」的浮层；悬停时箭头让位给叉，点叉解绑，芯片退回「选择工作区」空态，仍可点开重选）与**分支**（等宽字分支名，点开列本地分支、当前分支打勾）。分支是工作区仓库的属性，解绑后整枚分支芯片收起——不留禁用空壳、也不留上一份过期的分支名；重新绑定工作区时按该工作区检出的分支恢复。不再保留独立的「打开其他项目」入口，打开目录归入工作区浮层底部。
3. **能做什么** —— 三条真实可点的起点建议（读懂项目 / 跑测试 / 审阅改动），一行图标 + 文案 + 右箭头，不用卡片网格。

下方常驻快捷键提示：`Enter 发送 · Shift Enter 换行 · @ 引用文件 · $ 调用技能`。

去掉「预览版」胶囊——版本号归侧栏，标题区只承载主张。

### 7.3 审批闸门

三个层级，三种重量：

| 层级 | 外观 | 触发条件 |
| --- | --- | --- |
| 常规 | 1px 实线描边，白底，三选项齐全 | 可逆操作（写文件、执行只读命令） |
| 越界 | 1px **虚线**描边，白底，两选项 | 工作区之外（外部请求、越界路径） |
| 高危 | **整卡反白**，黑底白字，必须列目标与数量 | 不可逆操作（删除、覆盖、无版本控制的改动） |

**答完的记录**：闸门一旦裁决就折成一条只读记录——首行给结论（`已允许一次` / `已拒绝`）+ 来源标签（工作区外 / 不可逆）+ 工具名；第二行给**放行了什么**（等宽命令摘要，超长省略）与时间；点这一行展开，才露出当时的完整请求（说明、目标路径）与「你的决定 · 审批方式：逐次询问」。只写「已允许一次」是不够的——两周后回看必须知道当时放行了哪条命令、依据什么批的。记录不抬投影，也不再可交互。

**为什么不是红色**：

- 整屏黑白里，一块纯黑是视觉上最响的元素，比彩色更难无视。
- 红色在彩色方案里同时表示错误/删除/超时，语义被稀释；整卡反白只用在一处，实心填充只出现在按钮与控件尺度。
- 色弱用户完全不受影响。
- 可逆性通过描边风格区分（实线=可逆、虚线=越界、反白=不可逆），不是一个红色包打天下。

**硬约束**：
- 选项顺序永不改变：**拒绝永远最左，允许永远最右**。肌肉记忆比视觉一致性重要。
- 快捷键 `1 允许一次 / 2 总是允许 / 3 拒绝`，选项数量变化时 `3` 始终是拒绝。仅常规与虚线卡接受数字键；提示行不显示，按键仍生效。
- 拒绝按钮用红描边（`--danger`）：红色语义收拢为「止损」，与 diff 的删除红同源；黑卡上固定用亮红保证对比。
- 卡片获得焦点时，默认焦点是卡片本身，**不落在任何按钮上**。
- 高危卡不接受双击确认，也不接受数字键，必须逐个点击按钮——反射性连按不能成为放行不可逆操作的通道。
- 高风险类目下不提供"永不询问"，最多"总是允许当前这一个工具"。

### 7.4 右侧工作区

三段结构：**状态头**（分支、上下游、变更计数）/ **主滚动区**（已暂存、未暂存分组，等宽文件行，增删右对齐）/ **固定底栏**（提交框 + 终端预览）。

页签条 36px，选中项 2px `--ink` 下划线（去掉胶囊底），关闭按钮仅悬停出现。六类来源（文件 / Git / 技能 / 插件 / 浏览器 / 终端）走同一个加号菜单，已开页签不重复添加。右上角保留全屏与关闭。

### 7.5 设置

设置是**八个平级分区**，共用一套骨架：左侧常驻导航（五组，小号大写等宽组标题，不加分隔线，靠留白分组；标题栏面包屑跟随当前分区）；右侧内容区统一 660px（切页时标题列不横移），每页以「等宽小标 + 27px 标题 + 一句说明 + 2px `--ink` 墨线」开头，正文用**行式卡片**承载——标题与一句说明在左，状态 / 开关 / 按钮统一靠右。**除「个性化」「模型」这类需要编辑文本的分区外没有页脚保存**：设置项即时生效；只有编辑文本的页面才保留「取消 / 保存」草稿态。

| 分区 | 承载 | 关键决定 |
|---|---|---|
| 常规 | 审批方式、通知、运行环境、任务列表 | 审批方式用三张并排选择卡而非下拉——三个选项的差别在「打断程度」，必须并排比较；选中卡描边压深并给勾 |
| 外观 | 主题、字号、密度、动效 | 见下方细项 |
| 模型 | 用户自建的连接与模型清单 | Reins **不预置任何供应商**：名称、Base URL、API 格式、API Key、模型全部可编辑，左栏条目就是用户自己起的名字；主从两栏（178px / 自适应，总宽 660），不按提供方各开一页；API Key 用密码框 + 小眼睛临时明文；模型可单选 / 就地编辑 / 增删；底部删除项用危险色文字 |
| 个性化 | 用户级规则文件 | 等宽 13 / 1.9 编辑器 + 路径与 32 KB 预算；三条生效规则用编号行；唯一保留取消 / 保存的页 |
| 扩展管理 | 技能 / MCP / 插件 | 页签只做过滤（带数量），清单仍按类型分组；MCP 状态用徽标（已连接 / 连接失败）而非彩色点；插件启用行右端给开关 |
| 使用统计 | Token、构成、活动、按模型 | **先给构成条再给数字**——单看总量判断不了钱花在哪；构成条只用墨色深浅三档，不加彩色 |
| 已归档任务 | 归档列表 | 恢复与永久删除并排，危险项只用文字色；低频清理，不配筛选器 |
| 关于 | 版本、配置路径、运行方式 | 只读；只有「检查更新」「导出诊断包」两个动作 |

外观页细项：

- **主题**：三张微缩界面缩略图（跟随系统 / 浅色 / 深色），直接看见结果，不用色块。
- **字号**：滑杆 + 实时预览段落（12–18px，五档刻度）。
- **密度**：三档分段（紧凑 / 标准 / 宽松），不做连续滑杆，避免"半紧凑"这类无法调优的中间态。
- **开关行**：标题与说明左对齐，控件统一右对齐，扫描路径固定。新增开关：减少动效、工具卡默认展开、等宽连字（均给出默认值）。

模型页细项：

- **全部自定义**：供应商名是标题位上的输入框（不是只读文本），改名字实时同步左栏；Base URL、API 格式、API Key、模型 ID / 上下文 / 价格都能改；可添加、删除供应商，删空后右栏给空态引导。没有「内置 / 预设」这类只读项。
- **API 格式**：三种协议 `Anthropic Messages (/v1/messages)`、`Chat Completions (/chat/completions)`、`Responses (/responses)`，与产品 `web/src/settings/provider-detail.tsx` 的 `anthropic-messages` / `openai-completions` / `openai-responses` 一一对应。用与字段同宽的自绘菜单（不是原生 select）：选中行浅底 + 右侧勾，项名后跟等宽路径，菜单底部一句「格式决定请求体与路径；切换后请确认 Base URL」；触发行常显当前格式与路径。
- **API Key**：`type="password"`，右侧小眼睛切明文 / 遮蔽并换图标（eye / eye-off）；不做「更换」按钮和末四位摘要——字段本身就该可编辑，界面只在默认态遮蔽。
- **模型**：每行左侧单选（选中行描边压深 + 「当前」徽标），右侧铅笔进入就地三字段表单（模型 ID / 上下文 / 价格·备注），表单里可删除该模型；「+ 添加模型」直接开新行编辑。
- **草稿态**：切换供应商、增删、保存前把右栏写回数据；「取消」从上一次保存的快照整体回滚，「保存」更新快照并给出状态提示。密钥只写本机 `providers.json`，改名不影响历史任务。

## 九、可访问性

- **对比度**：正文 18.9:1，次文本 7.6:1，辅助 3.2:1（限非正文）。
- **焦点**：2px 实心墨色外描边 + 2px 偏移，深浅两套主题下均可见；不使用仅靠颜色的焦点提示。
- **命中区**：所有交互元素视觉尺寸之外扩到 44px（开关、复选框、图标按钮）。
- **动效**：全部动画带 `prefers-reduced-motion` 降级；另提供手动「减少动效」开关（手动优先于系统）。全局节奏统一 160ms 缓动：浮层下移淡入；闸门与 diff 在用户切换页面时级联入场（首屏与深链接不播入场动效）；可点元素按压下沉 1px；侧栏行悬停时时间戳与操作原位交叉淡入；上下文圆环呈现时从空环充到当前值。
- **文字缩放**：字号可调 12–18px，布局不破；浏览器 200% 缩放不出现横向滚动。
- **语义**：状态图标配 `aria-label`；审批卡 `role="alertdialog"`；页签 `role="tab"` + `aria-selected`；菜单 `aria-haspopup` / `aria-expanded`。
- **行控件可聚焦**：会话行、工具行、页签这类"看似一行"的交互元素，落地时必须是可聚焦控件（button 或等价 role + tabindex），焦点态与悬停态等效；工具行展开是主路径，必须键盘可达。
- **动效降级不产生不可见内容**：`prefers-reduced-motion` 下，扫光文字这类"背景裁剪"动效直接替换为纯色文本，而不是仅冻结时长。
