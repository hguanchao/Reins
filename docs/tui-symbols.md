# TUI 可用符号参考

终端能显示哪些符号取决于字体与终端本身，没有一个固定的「全部可用」清单。本文按 TUI 实际用途整理常用符号区段；标注为「全量」的区段已逐字符列出，其余给出常用子集与完整 Unicode 范围。

选择符号时优先考虑：等宽对齐是否稳定、字体是否普遍支持、是否会被终端当作 emoji 渲染。

---

## 一、范围速查

| 类别 | Unicode 范围 | 说明 |
| --- | --- | --- |
| 制表符 | U+2500–U+257F | 单线、粗线、双线、圆角、虚线 |
| 块元素 | U+2580–U+259F | 半块、密度、柱状图 |
| 几何图形 | U+25A0–U+25FF | 方块、圆、三角、菱形 |
| 箭头 | U+2190–U+21FF | 基本箭头 |
| 杂项符号 | U+2600–U+26FF | 状态、天气、棋牌、警告 |
| Dingbats | U+2700–U+27BF | 勾叉、星形、装饰符号 |
| 盲文点阵 | U+2800–U+28FF | 256 种点阵，适合图表与 spinner |
| 补充箭头 A | U+27F0–U+27FF | 长箭头 |
| 补充箭头 B | U+2900–U+297F | 更多箭头 |
| 杂项符号与箭头 | U+2B00–U+2BFF | 部分箭头与几何符号 |
| 带圈字母数字 | U+2460–U+24FF | ①、Ⓐ、❶ |
| 数学运算符 | U+2200–U+22FF | ∑、√、∞、≈、≤、≥ |
| 杂项技术符号 | U+2300–U+23FF | ⌘、⌥、⌫、⏎、⏵ |

## 十四、Powerline 与 Nerd Font

这些是私有区字符，必须安装对应字体，否则显示为方块或空白。

Powerline 分隔符：

```text
U+E0A0–U+E0B3
```

Nerd Font 图标分布：

```text
U+E000–U+E7FF
U+E900–U+E9FF
U+EA60–U+EBEB
U+F000–U+F2FF   Font Awesome
U+F300–U+F3FF   Material Design
U+F400–U+F4FF   Octicons
U+F500–U+F8FF   其他图标
```

常见用途：分支、文件夹、文件、终端、Git、锁、搜索、齿轮、语言图标。没有 Nerd Font 时建议改用文字或几何符号。

## 十五、Emoji

范围很大，常用 UI 示例：

```text
✅ ❌ ⚠️ ℹ️ 📁 📄 ⚙️ 🔍 🚀 ✨ 🔥 💡 🐛 🎉 🔒 🔓 ⏳ ⌛
```

注意：

- 通常占 2 列，会破坏等宽对齐。
- 会受 `\uFE0F`、`\uFE0E`、ZWJ 序列和终端字体影响。
- `✅`、`❌` 是 emoji；想要 1 列文本请用 `✓`、`✗`。

## 十六、宽度与兼容性

| 类别 | 通常宽度 | 注意 |
| --- | --- | --- |
| ASCII | 1 | 最安全 |
| 盲文点阵 | 1 | 宽度稳定 |
| 制表符 | 1 | 属 Ambiguous，CJK 终端可能按 2 列 |
| 块元素 | 1 | 同上 |
| 几何图形 | 1 | 同上 |
| 箭头 | 1 | 同上 |
| 杂项符号/Dingbats | 1 或 2 | 可能被当作 emoji |
| Emoji | 2 | 不建议用于对齐 |
| Powerline/Nerd Font | 1 | 需要专用字体，否则豆腐块 |

项目里已有 `get-east-asian-width`，当前 `eastAsianWidth()` 会把 Ambiguous 当作 1 列；如果终端把它渲染成 2 列，实际对齐会偏。因此固定网格布局优先用 ASCII、盲文、制表符，或者在实际终端里验证。

## 十七、当前 Reins TUI 已用

目前用了：

- `─`：输入框上下边框
- `›`：输入提示符与用户提示前缀
- `…`：用户提示超过三行时的截断标记
- `⠋ ⠙ ⠹ ⠸ ⠼ ⠴ ⠦ ⠧ ⠇ ⠏`：输入框上方的运行时状态加载动画，文字带扫光效果；状态行还显示活动描述、计时与 token 数
- `│` / `█`：消息滚动条的轨道与滑块，颜色 `#242424`；滚轮或拖动滚动条可翻看更旧的消息，最新提示发送后翻到顶部
- 用户提示：背景 `#242424`，上下各留一行背景；前缀 `#c8c8c8`，正文 `#e1e1e1`，最多三行；作为吸顶 header 时下方固定 1 行 gap
- ANSI 控制序列：备用屏、光标定位、光标形状、焦点上报、鼠标上报、用户提示背景色（`#242424`，`\x1b[48;2;36;36;36m`）
- 焦点颜色：输入框边框与 `›` 聚焦时 `#e1e1e1`，失焦时 `#242424` 并隐藏光标；点击输入框外失焦，点击输入框内恢复

没有引入 Nerd Font、Powerline 或 emoji 依赖。
